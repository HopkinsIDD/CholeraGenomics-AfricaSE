# CholeraGenomics-AfricaSE

R code and supplemental data needed to generate raw figures for the manuscript: [Whole genome sequencing and transmission analysis of Vibrio cholerae isolates from Eastern and Southern Africa: a genomic epidemiology study](https://www.medrxiv.org/content/10.1101/2024.03.28.24302717v2).

- Required packages are listed in the `figure_code.Rmd` file. Running this file within this repository will generate all manuscript figures from supplemental data provided in this repository. These data are also provided as part of the manuscript, as appendices numbered accordance with journal polices.

- The tree file provided as `Appendix4.tree` can be used in FigTree, iTOL, or other tree visualization software. Alternatively, these data are now available on the interactive Microreact platform [here](https://microreact.org/project/2pnZx9QKsZGrfDAKiwJAd2-vibro-cholera-from-eastern-and-southern-africa).
