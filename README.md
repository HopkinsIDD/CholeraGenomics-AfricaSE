# CholeraGenomics-AfricaSE

The R codes and supplemental data to generate raw figures for the manuscript: "Whole genome sequencing and transmission analysis of Vibrio cholerae isolates from Eastern and Southern Africa: a genomic epidemiology study"

- Make sure you installed the required the packages. Please run the script within this repo. The supplemental data and the map folder contains dependent data.

- [Link to the manuscript](https://www.medrxiv.org/content/10.1101/2024.03.28.24302717v2)
